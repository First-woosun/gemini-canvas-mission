# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱

### 앱 이름
- LunchBoxMaker

### 배포 링크

- [배포 링크](https://gemini.google.com/share/3ad06e6c5840)

### 이 앱을 만든 이유

- 점심 도시락을 준비할 떄 어떤 메뉴로 도시락을 쌀지 고민하는 시간을 절약하기 위해 제작

### 주요 기능

- 카테고리 별로 미리 준비되어 있는 레시피 중 하나를 랜덤으로 추천
    - 카테고리는 AI 추천, 초스피드, 다이어트, 가성비, 전날준비가 있음

### AI 기능 (해당되는 경우)

- AI 추천 버튼을 통해 Gemini 모델이 생성한 레시피를 추천받을 수 있음
- 미리 준비되어 있는 레시피가 마음에 들지 않는 경우 활용

## 🎮 2. 게임

### 앱 이름
- GoStoneShooting (알까기)

### 배포 링크

- [배포 링크](https://gemini.google.com/share/1a50151f7950)

### 이 앱을 만든 이유

- 알까기 게임을 통해 상대방의 바둑알을 날리며 스트레스를 풀기 위해

### 주요 기능

- 플레이어 2명이 턴을 주고받으며 바둑알을 발사
    - 발사 할 바둑알을 드레그하여 발사 강도와 방향 조절
- 바둑알기리 충돌하여 바둑판 바깥으로 나간 경우 해당 바둑알은 탈락
- 각 플레이어의 남은 바둑알 갯수 카운팅
- 현제 턴의 플레이어가 누군지 표시해주는 라벨

## 📚 3. 학습 앱

### 앱 이름
- KotlinDocs

### 배포 링크
- [배포 링크](https://gemini.google.com/share/7be3f8e8e9d5)

### 이 앱을 만든 이유

- 앞으로 과제를 수행하면서 Kotlin 공식 문서를 참고할 때 도움을 받기 위해

### 주요 기능

- 카테고리 별 요약 내용
- Gemini를 통한 카테고리 별 퀴즈 출제와 질문

### AI 기능 (해당되는 경우)

- 카테고리 별로 Gemini 체팅창을 삽입하여 해당 카테고리에 대한 질문을 바로바로 할 수 있음
- 퀴즈 출제 버튼을 통해 해당 카테고리에 관해 AI가 퀴즈를 출제해줌
